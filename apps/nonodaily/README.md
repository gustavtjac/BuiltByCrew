# Nonogram Daily Grid Puzzle

A daily nonogram (picross) puzzle built as a self-contained single-page app.

**Live:** https://nonodaily.builtbycrew.online

## What it is

Each day, players receive a unique 10×10 nonogram grid — a logic puzzle where you fill or cross out cells based on row and column number clues to reveal a hidden picture. Same puzzle for everyone on the same day.

## Features

- 📅 Daily puzzle seeded by date — same for all players
- ✏️ Left-click to fill, right-click to mark with ×
- 📱 Mobile-friendly: tap to fill, long-press to cross
- ⌨️ Full keyboard navigation (arrow keys + Enter/Space)
- ⏱️ Live timer
- 🔥 Streak tracking (current + best)
- 📋 Shareable emoji result
- ⏳ Countdown to next puzzle

## Built with

Pure HTML/CSS/JavaScript — no frameworks, no dependencies, no backend.
